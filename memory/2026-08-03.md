## The module arc

Each module names the module it depends on, per the dependency test:

1. The problem Shannon solved (motivation gear)
2. Entropy, relative entropy and mutual information as one object ← M01
3. AEP, typical sets, method of types ← M02
4. Lossless source coding: Kraft, Huffman, arithmetic, ANS ← M03
5. Universal compression: LZ, MDL, Kolmogorov complexity ← M04, M03
6. Channel capacity and the noisy-channel coding theorem ← M03, M02
7. Gaussian channels, water-filling, power vs bandwidth ← M06
8. Codes that reach capacity: turbo, LDPC, polar, finite blocklength ← M06, M07
9. Rate–distortion, separation, neural transform coding ← M06, M07
10. Multi-user IT and where the theory is incomplete ← M06, M09
11. IT as a tool for statistics and ML ← M02, M03, M06, M09
12. Information, physics and computation ← M02, M03 (**optional** — nothing
    depends on it; flagged as skippable in the routes section)
13. Applications at the edges, and what is still open ← everything

## Stylesheet fix (the one non-obvious change)

`.cite` carried `white-space: nowrap`, which forced horizontal page scrolling at
380 px for any citation whose label was longer than the viewport — measured
scrollWidth 849 px against clientWidth 380 px, with citation anchors up to
565 px wide. This is a **latent bug affecting every future page**, not something
specific to this topic: real academic titles run to 70+ characters and no
citation label can be kept under ~35.

Fixed while preserving the evident design intent (the `R-NN` code must never
orphan from its title):

```css
.cite { overflow-wrap: break-word; }          /* was: white-space: nowrap */
.cite::after { content: "\00a0" attr(data-code); white-space: nowrap; }
```

The non-breaking space glues the code to the last word, so the title wraps but
the code cannot separate. Verified: 380 px scrollWidth is now exactly 380.

## Deliberately left out

- Quantum Shannon theory — separate subject, listed under "where to go next".
- The algebraic half of coding theory (finite fields, BCH/Reed–Solomon
  constructions) — one paragraph of context in M08, then pointed elsewhere.
- Measure-theoretic IT on abstract alphabets; algorithmic randomness past the
  invariance theorem; information geometry.
- *A Mind at Play* (Soni & Goodman) — wanted it for M01's history, but both
  Simon & Schuster URLs return 403 to every checker, so there was no verifiable
  canonical link. Cut rather than guessed; *The Bit Player* documentary covers
  the same ground and does verify.

## Notes for next time

- `README.md`'s suggested check `grep -c 'rail-item'` **over-counts by 3** on a
  template-conformant page, because the "Also" rail list has three entries. Use
  `grep -c 'class="module"'` against the first rail list only.
- `itsoc.org`, `encode.su`, `github.com` and `youtube.com` all block scripted
  link checking from this environment. GitHub verifies through WebFetch;
  itsoc.org verifies through search results only.
- The syllabus body runs ~9,100 words against `CLAUDE.md`'s stated 2,500–5,000
  guide. Roughly 1,760 of those are citation lists rather than prose, and the
  rest is 13 modules at the depth bar. Worth a decision next time whether the
  guide is a target or a floor.
