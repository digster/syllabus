# 2026-08-05 — Crypto and blockchain, split into two topic pages

## The request

"Add a new syllabus for crypto/blockchain and its ecosystem (nft, defi, dao etc)."

## The scoping decision

The topic spans two genuinely different courses — a protocol/systems-engineering
one (cryptography → consensus → EVM → rollups → ZK) and an economics/mechanism-
design one (AMMs, lending, stablecoins, MEV, NFTs, DAOs, regulation). Written as
one page, one of the two layers has to be thinned below the repo's depth bar.
Asked; the answer was **split into two cross-linked pages**. That is what shipped.

## Page A dependency chain

M01 pre-Bitcoin digital cash → M02 primitives (hashes, Merkle, ECDSA/Schnorr,
BIP-32) → M03 Bitcoin (UTXO, Script, SegWit/Taproot, policy vs consensus) → M04
Nakamoto consensus analysed (Backbone properties, selfish mining, 51% economics)
→ M05 classical BFT (FLP, DLS, PBFT, HotStuff, accountable safety) → M06 proof of
stake (Gasper, slashing, weak subjectivity, inactivity leak) → M07 EVM (account
model, MPT, gas, DELEGATECALL, EIP-1559, 4337/7702) → M08 contract security →
M09 rollups/DA/PBS → M10 zero-knowledge → M11 nodes and client diversity →
M12 bridges and shared security → M13 protocol governance and frontier.

M11 could sit earlier (networking underpins M04's propagation assumption); it is
placed late deliberately so the reader knows what is being gossiped first.

## Page B dependency chain

M01 what a crypto asset is → M02 tokenomics → **M03 AMMs (the spine)** → M04
lending and liquidation → M05 stablecoins → M06 oracles → M07 MEV → M08
composability and the exploit taxonomy → M09 NFTs → M10 DAOs → M11 identity and
public goods (flagged optional on the short path) → M12 regulation → M13
institutions and what actually replicated.

M03 is the load-bearing module: M04, M06, M07 and M08 all assume you can reason
about a bonding curve and about who loses money to whom.

## Deliberate boundary between the two pages

MEV is split. The **plumbing** — proposer–builder separation, mev-boost relay
topology — is Page A M09. The **market** — sandwiching, CEX-DEX arbitrage, order
flow auctions, builder centralisation — is Page B M07. Each page says so and
links the other. Page B's `#before-you-start` sends readers to Page A M01–M03 and
M07–M08 rather than re-teaching the account model.
