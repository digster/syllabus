## Method

Same generate-don't-maintain approach as the blockchain rebuild, in two scripts
(scratchpad, not the repo):

1. `add_video.py` — inserts the resource blocks with throwaway ids
   (`r-901…r-914`), inserts the module citations, then renumbers **every**
   resource id in document order and rewrites every reference. It exits without
   writing if any citation dangles or any resource is uncited.
2. `reorder_talks.py` — reorders the Talks group by citing module and renumbers
   again. Renumbering being free is what made reordering thinkable at all; the
   group would otherwise have been fourteen entries in the order I found them.

The renumber has to rewrite prose too. Thirty-odd `r-note` and group-intro
sentences on this page name resources inline ("R-19 is the option if you learn
by watching", "Read the FSE code against R-70 and R-76"), and an id-only rewrite
would have left every one of them pointing at the wrong resource — silently,
because no anchor breaks. The scripts map every `r-NN`/`R-NN` token in the file.

`audit.py` reimplemented and **validated against the pre-change copy of the page
before being trusted** — 94 resources, 0 failures — then run on the new page:
108 resources, 155 citations, 0 failures. Checks module ids and the six required
parts in order, one citation per `.assigned li`, rail-to-module correspondence,
gapless ids, `data-code` ↔ visible `R-NN`, `r-used` set equality both ways, every
`#…` anchor resolving, all five count sites, and the style rules.

Playwright at 380/768/1280 px with JS on and off, on the topic page and the
catalog: no horizontal overflow, no dead in-page anchors. Launched with the
explicit `executablePath` and with non-`file:` requests aborted, which also
sidesteps the Google Fonts stall that timed out the first run.

## Link verification

Every new URL fetched with curl and a browser user agent. Canonical
non-video homes preferred and found for most of them: Simons Institute talk
pages (Arıkan, Orlitsky, Dwork), the Stanford EE380 colloquium abstract page
(Tishby), the MLSys seminar index (Rae), the ICLR virtual workshop page, the
NPS Hamming resources page, the EE274 course site, `3blue1brown.com`,
`preposterousuniverse.com`.

Three entries link a platform because no other home exists: two YouTube
playlists (Wilde's PHYS 7347, the Art of the Problem × IEEE series, the Bell
Labs centennial) — all three returned **200** to curl with a browser UA, so no
caveat was needed.

Kept with the refusal stated in brackets: **Khan Academy**, which returns a
Cloudflare "Client Challenge" body to curl (HTTP 200, no content) and opens
normally in a browser. Nothing carries `tag--unverified`.

Two hosts refused everything and cost nothing, because nothing was cited from
them: `itsoc.org` (403, Cloudflare — as already recorded in LEARNINGS) and
`media.itsoc.org`, which **no longer resolves at all**. The latter is the host
LEARNINGS' own School-of-Information-Theory pointer would have sent a future
session to.
